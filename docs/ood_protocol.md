# Synthetic OOD Evaluation Protocol

FailureLens v0.2 treats OOD detection as a hypothesis test:

- Null hypothesis: a new input is exchangeable with the ID calibration data.
- Alternative: the input is not generated by the ID distribution.

## Data partitions

The demo uses four disjoint data sources:

1. **ID training:** fits the classifier.
2. **ID calibration:** calibrates conformal p-values and never updates model parameters.
3. **ID test:** estimates the false-alarm rate.
4. **OOD test:** estimates detection power and ranking metrics.

Do not choose thresholds with the OOD test labels when claiming an unsupervised deployment guarantee.

## OOD groups

- **Near-OOD:** shifted, higher-variance mixtures that overlap the ID support.
- **Far-OOD:** points sampled on a ring far from all ID class centers.
- **High-confidence OOD:** far-away candidates explicitly selected for high classifier confidence.

The third group is a stress test, not an unbiased sample from a naturally occurring OOD distribution.

## Score convention

Every FailureLens OOD score uses the same direction: larger means more OOD-like. This prevents accidental metric reversal.

The demo contrasts output-only scores with a class-conditional Mahalanobis distance fitted on ID training embeddings. The distance baseline can detect geometric novelty that a highly confident discriminative output may hide, but its quality still depends on the learned representation and covariance estimate.

## Conformal calibration

For calibration scores `s_1, ..., s_n` and test score `s`, the conservative upper-tail p-value is:

```text
p(s) = [1 + count(s_i >= s)] / (n + 1)
```

Reject the ID null when `p(s) <= alpha`. Under exchangeability, this gives marginal finite-sample Type-I error control. It does not guarantee high OOD power and does not remain valid under arbitrary ID distribution shift.

## Reporting

Report the following separately for every OOD group:

- AUROC, with OOD as positive;
- AUPR-OOD;
- FPR at 95% OOD TPR;
- conformal rejection power;
- ID false-alarm rate at each chosen alpha.

Always state which distribution is positive when reporting AUPR or FPR.

## Medical-imaging extension

For multi-site medical imaging, use patient-level partitions and reserve calibration patients that are independent of training patients. Report false alarms and power by site, scanner, demographic subgroup, disease class, and acquisition protocol. A subgroup with high OOD scores may indicate model undercoverage rather than erroneous data and should not be automatically removed.
